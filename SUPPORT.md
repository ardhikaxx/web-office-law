## 🧭 Sebelum Mengajukan Pertanyaan

1. Pastikan lingkungan pengembangan memenuhi syarat: **PHP 8.3/8.4+**, **Composer 2.x**, dan **Node.js 18+**.
2. Pastikan asset CSS telah dikompilasi dengan menjalankan: `npm run build`.
3. Jalankan `php artisan test --compact` untuk memverifikasi integritas seluruh komponen sistem.
4. Periksa file `storage/logs/laravel.log` bila menemukan kendala atau galat pada server.
5. Sertakan informasi versi PHP/Node, tangkapan layar, dan langkah reproduksi saat menghubungi tim pengembang.

## 🛠️ Layanan Kustomisasi

Membutuhkan solusi website hukum profesional untuk firma atau kantor hukum Anda? Layanan kustomisasi yang tersedia meliputi:

* Penyesuaian identitas visual, logo, dan profil advokat mitra (*partners & associates*).
* Penambahan landing page otoritas lokal untuk kota lain (Jakarta, Bandung, Surabaya, Medan, Semarang, Bali).
* Integrasi portal manajemen perkara klien (*client case tracking*), portal pembayaran retainer, atau billing online.
* Setup hosting VPS/Cloud, optimasi CDN, dan audit teknis Google Search Console / Core Web Vitals.
* Lisensi penggunaan komersial resmi untuk kantor hukum Anda.

> *Catatan: Penggunaan komersial tanpa izin tertulis dari pemilik hak cipta melanggar ketentuan [LICENSE](./LICENSE).*
